# legacy — 历史版本存档

本目录存放「联盟数据包获取」工具的**早期实现**,仅作参考与追溯,**不参与现行 GUI 版本(`src/`)的运行**。

## 文件

| 文件 | 说明 |
|---|---|
| `lol_material_cli_v1.py` | v1 单文件命令行版本(原文件名含中文与 `&`,已规范化重命名)。基于 `input()` 菜单交互,在单个文件内串起下载、解压、汉化整理的完整流程。 |

## 与现行版本(v2)的关系

- v2(`src/`)是模块化的 Flet 图形界面重写版,与本脚本**无任何代码依赖**(互不 import)。
- 保留 v1 仅为记录早期思路与官方接口用法;后续若重写为 Tauri 版,本目录可作为业务逻辑的参考来源之一。

> ⚠️ v1 脚本未经现行环境验证,可能依赖已变更的官方接口,直接运行前请自行核对。
